# 앱 대화를 Discord에서 이어가기

한국어 | [English](desktop-input.en.md)

ChatGPT/Codex 데스크톱 앱에서 시작한 Codex 작업은 **이미 동기화된 같은 Discord 스레드에 일반 메시지로 답하면** 앱의 원래 대화로 전달됩니다. `/fork`나 터미널 선택이 필요하지 않습니다.

- 앱에서 작업 중이면 중간 입력으로 전달합니다. 진행 중인 턴이 없다고 앱이 명시적으로 응답하면 같은 대화의 다음 턴을 시작합니다.
- 모델·권한·작업 폴더·스타일은 앱의 기존 설정을 따릅니다. 커넥터가 별도 writer를 열거나 응답 앞에 스타일 지침을 추가하지 않습니다.
- 답변 알림은 기존 세션 동기화를 사용합니다. `/fork` 등 봇 명령은 기존대로 동작하며, 명시적으로 연결한 Orca 터미널은 우선합니다.

## 적용 조건

Direct Gateway와 앱이 **같은 컴퓨터·사용자·Codex 홈**을 사용해야 합니다. 현재 macOS/Linux의 사용자 소켓 연결을 지원하며 Windows named pipe는 지원하지 않습니다. 앱이 이 대화를 관리하고 있어야 합니다. 소켓이나 소유자가 없으면 기존 커넥터 처리로 돌아갑니다.

소스 업데이트와 의존성 설치 후 **Gateway만 재시작**하면 기본으로 켜집니다. Worker나 앱을 재시작할 필요는 없습니다. Gateway 환경에 `CONNECT_DESKTOP_INPUT_ENABLED=false`를 설정하면 끌 수 있습니다.

일반 ChatGPT 웹 채팅은 대상이 아닙니다. 이 기능은 앱의 로컬 Codex 작업 세션에 연결합니다. 앱이 제공하는 동일 사용자 IPC의 owner discovery / follower 프로토콜을 사용하며 공개적으로 안정성이 보장된 API는 아닙니다. ChatGPT 앱 `26.928.20755`와 번들 Codex `0.159.0`에서 원래 대화의 소유자 탐색을 확인했습니다. 앱 업데이트로 프로토콜이 달라지면 커넥터 호환성 수정이 필요할 수 있습니다.

## 전달과 복구

- 채널의 기존 역할 권한을 확인합니다. 봇/relay 메시지, 복원된 대기 요청은 앱에 자동 전달하지 않습니다.
- 텍스트만 지원합니다. 첨부 파일, 권한 승인, 선택형 질문의 전용 버튼은 앱에서 처리하세요. 현재 기능은 일반 대화 입력이며 승인 응답을 자동으로 선택하지 않습니다.
- `.connect/desktop-deliveries.json`에 7일간 메시지 ID와 전송 상태를 보관합니다. 프롬프트나 대화 본문은 저장하지 않습니다. 업데이트 시 이 파일을 보존하세요.
- 앱 연결이 끊기거나 응답을 확인할 수 없으면 다른 대화나 새 writer로 재전송하지 않습니다. 앱에서 반영 여부를 확인하고 필요한 경우 새 메시지로 보내세요. 기록이 손상되면 먼저 복구해야 합니다.
- 동일 세션의 소유자를 찾은 뒤에는 그 소유자에게만 입력합니다. 앱이 닫히거나 소유자가 바뀌면 전달을 중단합니다. 실제 전달 확인은 앱의 응답이며, 작업 완료를 의미하지 않습니다.

[공식 App Server 문서](https://learn.chatgpt.com/docs/app-server#steer-an-active-turn)는 진행 중인 턴에 입력을 추가하는 `turn/steer`를 설명합니다. 이 커넥터는 별도 app-server를 시작하는 대신 앱의 follower 연결을 통해 앱에 해당 동작을 요청합니다.
